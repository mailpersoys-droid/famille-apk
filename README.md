# Famille

Installation et mises a jour de l'app familiale (Android).

Page d'installation : https://mailpersoys-droid.github.io/famille-apk/

`famille-version.json` dit quelle version est la derniere ; l'app le lit depuis
l'onglet Reglages, telecharge l'APK depuis la release GitHub et l'installe.
Publie par `./maj.sh` depuis ~/famille.
